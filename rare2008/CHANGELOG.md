`index.html` 은 `src/build.py` 가 `src/deck.src.html` 과 `src/img/` 로 만든 결과물이다. 직접 고치지 말고 원본을 고친 뒤 다시 빌드한다.

## v1.2 — 2026-11-14
- 6장 무한(∞): 선을 따라 도는 빛이 크롬·안드로이드에서 멈춰 있던 문제 수정. 선 길이 값에 단위(px)가 없어 크롬이 움직임 계산을 못 했다(사파리는 됐음).

## v1.1 — 2026-11-14
- 9장 시음 적기: 2021 출시 → 2026 성숙기 시작 → 오늘 → 2040+ 로 표시. "지금부터 2040년 이후까지"가 가장 좋은 때라는 띠와 시음 평 인용 추가.
- 손님 화면: 따라보는 동안은 직접 넘기지 못하게 잠그고 넘김·전체 화면 단추를 감춤. 화면을 누르면 전체 화면이 됨(브라우저가 지원할 때). 따라보기를 끄면 직접 넘겨볼 수 있음.
- 첫 장 안내 문구를 손님용으로 따로 표시.

## v1.0 — 2026-11-14
- GitHub Pages 공개판 첫 배포. 13장, 사진은 페이지 안에 내장.
- 넘김 연동: ntfy.sh 공개 중계 사용. 진행자 주소로 연 기기만 넘기고, 나머지는 따라보기만 한다. 오가는 것은 장 번호뿐.

- 낮은 가로 화면에서는 장 내용을 통째로 줄여 아래 띠에 가리지 않게 맞춘다.
